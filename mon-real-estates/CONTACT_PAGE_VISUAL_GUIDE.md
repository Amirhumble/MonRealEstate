## 🎯 Interactive Elements

### Google Maps
```
User Actions:
1. Zoom In/Out → Mouse wheel or +/- buttons
2. Pan → Click and drag
3. Street View → Drag yellow person icon
4. Full Screen → Click expand button
5. Open in Google Maps → Click map
```

### Get Directions Button
```
┌─────────────────────────────────┐
│  🧭 Get Directions              │
└─────────────────────────────────┘

On Click:
- Opens Google Maps in new tab
- Pre-filled destination
- Shows route from user location
- Works on mobile and desktop
```

### Quick Contact Cards
```
┌──────────┐  ┌──────────┐
│ 📞 Call  │  │ ✉️ Email │
└──────────┘  └──────────┘

On Click:
- Phone: Opens dialer (mobile) or Skype (desktop)
- Email: Opens email client with pre-filled address
```

### Hover Effects
```
Element          | Hover Effect
─────────────────|──────────────────
Office Card      | None (static)
Quick Contact    | Lift (-translate-y-1)
                 | Shadow increase
Get Directions   | Background darken
                 | Shadow increase
Social Links     | Background tint
```

## 📱 Responsive Behavior

### Breakpoint: 1024px (Desktop)
```
Layout: Two columns (50/50)
Map: Left side, full height
Details: Right side, stacked
Grid: lg:grid-cols-2
```

### Breakpoint: 768px (Tablet)
```
Layout: Two columns (adjusted)
Map: Left side, responsive height
Details: Right side, compact
Grid: Still 2 columns
```

### Breakpoint: < 768px (Mobile)
```
Layout: Single column
Map: Full width, 4:3 ratio
Details: Stacked below map
Grid: 1 column
Cards: Full width
```
